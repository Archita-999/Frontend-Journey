#Frontend Journey

A beginner project built while learning frontend development. It includes a responsive page, and a working TO-DO list.

Live Demo: https://archita-999.github.io/Frontend-Journey/

## What it does?
- Responsive layout with a navbar, hero section and project cards.
- Counter and reset buttons.
- To-do list, where we can add, complete and delet tasks.
- Tasks are saved in the browser using local storage.

## Built with
HTML, CSS, JavaScript

## What I learned
- I learned about basic HTML tags, and CSS properties. 
- I learned about conditions, loops, array, functions, objects and DOMS.
- I fixed bugs with the help of console, I did not really make big mistakes. Silly mistakes like spellings, Camel case, and different functions name. With the help of console red lines, I'm able to recognize bugs and fix it.
